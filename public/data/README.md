# Indonesia boundary data

`indonesia-natural-earth.geojson` contains the Indonesia feature extracted from Natural Earth `ne_110m_admin_0_countries`.

- Source: Natural Earth vector data, release 5.1.2 repository
- Source URL: https://github.com/nvkelso/natural-earth-vector
- License: public domain
- Retrieved: 24 October 2026
- Use: contextual Indonesia boundary in the Explore Indonesia atlas

Landmark markers are generated from coordinates recorded by official Indonesian cultural-heritage registries in `src/data/heritage.ts`.
